Frequently asked questions

Can’t find an answer? Ask the team.

Which frameworks does Ferry support?

Anything that produces static files or a Node, Bun or Deno server: Next.js, Remix, Astro, SvelteKit, Nuxt, Vite and plain HTML are detected automatically.

Do previews use my production database?

Never by default. Each preview gets a branch of your database seeded from a sanitised snapshot, deleted when the pull request closes.

How is bandwidth counted?

Only responses served to visitors count. Builds, previews opened by your team and cache fills between regions are free.

Can I bring my own CI?

Yes. Run ferry deploy --prebuilt from GitHub Actions, GitLab or Buildkite and keep previews, rollouts and metrics.

Is there a discount for open source?

Public repositories with an OSI-approved licence get the Team plan free. Apply from your project settings.
