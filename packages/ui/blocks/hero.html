Your database, branched like code

Fork production Postgres in under a second, run the migration against real data, and merge it back when the review passes. Strata copies on write, so a branch costs nothing until it diverges.

Create a branch Read the docs 
$ strata branch create fix-invoice-totals --from main
✓ Branched main (48.2 GB) in 0.4s
  postgres://fix-invoice-totals.db.strata.dev/app

$ strata migrate --branch fix-invoice-totals
  Applying 0042_invoice_totals_numeric.sql
✓ 1 migration applied, 1,204,331 rows rewritten in 12.8s

$ strata diff fix-invoice-totals main
  ~ invoices.total  integer → numeric(12,2)
Branch fix-invoice-totals · 212 MB diverged from main Ready to merge
